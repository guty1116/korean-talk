      はじめに♡ 無料キーの設定

      ミナの会話にはGoogleのAI「Gemini」を使います。無料のキーを一度だけ設定してください。

      1. Google AI Studio のAPIキーページを開き、Googleアカウントでログイン
      2. 「APIキーを作成（Create API key）」を押す
      3. 表示されたキー（AQ. または AIza で始まる文字列）をコピーして、下に貼り付け
      1. Google AI Studio의 API 키 페이지를 열고 Google 계정으로 로그인
      2. 「API 키 만들기（Create API key）」를 누르기
      3. 표시된 키（AQ. 또는 AIza로 시작하는 문자열）를 복사해서 아래에 붙여 넣기

      キーはこのブラウザの中にだけ保存され、Googleとの通信以外には使いません。他の人に見せないでください。
